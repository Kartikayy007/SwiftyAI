# SwiftyAI

SwiftyAI is a Swift SDK for building text generation, streaming, tools, provider routing, Swift app state, MCP clients, and observability on top of multiple AI providers.

## What it does

SwiftyAI gives Swift developers one consistent surface for common AI product work. You can generate text, stream responses, call tools, create structured objects, observe calls, and connect discovered MCP tools.

## Why it matters

Provider APIs are different enough that small prototypes turn into provider glue quickly. SwiftyAI keeps your application code focused on product behavior while the SDK handles model protocols, request options, streaming chunks, tool loops, and provider specific encoding.

<Callout title="SDK first">
The SDK ships APIs and state primitives. It does not require adopting prebuilt app screens.
</Callout>

## Before you start

1. Add SwiftyAI to a Swift package or Xcode project.

2. Configure at least one provider key.

3. Pick either direct model instances or the [provider registry](/docs/provider-registry).

## Example

```swift
import Swifty_AI

let model = OpenAICompatibleProvider(
    baseURL: "https://api.openai.com/v1",
    apiKey: ProcessInfo.processInfo.environment["OPENAI_API_KEY"]!,
    model: "gpt-4o-mini"
)

let response = try await generateText(
    model: model,
    prompt: "Explain actors in Swift in three sentences."
)

print(response.text)
```
