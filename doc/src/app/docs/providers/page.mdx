# Providers

SwiftyAI includes concrete providers plus an OpenAI-compatible adapter. The SDK API stays the same; the provider decides how requests are encoded.

## Built-In Prefixes

`AI.configure` supports these model string prefixes:

- `openai`
- `anthropic`
- `gemini`
- `groq`
- `openrouter`
- `mistral`
- `cohere`
- `cloudflare`
- `ollama`

```swift
AI.configure { ai in
    ai.openAI(apiKey: openAIKey)
    ai.anthropic(apiKey: anthropicKey)
    ai.gemini(apiKey: geminiKey)
    ai.groq(apiKey: groqKey)
    ai.ollama(baseURL: "http://localhost:11434/v1")
}

let response = try await generateText(
    model: "anthropic/claude-3-5-sonnet-latest",
    prompt: "Write a concise migration note."
)
```

## Direct Provider Types

Use direct providers when you want explicit construction.

```swift
let openAI = OpenAICompatibleProvider(
    baseURL: "https://api.openai.com/v1",
    apiKey: openAIKey,
    model: "gpt-4o-mini"
)

let anthropic = AnthropicProvider(
    apiKey: anthropicKey,
    model: "claude-3-5-sonnet-latest"
)

let gemini = GeminiProvider(
    apiKey: geminiKey,
    model: "gemini-2.0-flash"
)
```

`AppleFoundationProvider` is available when the target can import `FoundationModels`.

## OpenAI-Compatible Providers

`OpenAICompatibleProvider` powers OpenAI plus compatible APIs such as Groq, OpenRouter, Mistral, Cohere, Cloudflare, Ollama, and private gateways.

```swift
let local = OpenAICompatibleProvider(
    baseURL: "http://localhost:11434/v1",
    apiKey: "ollama",
    model: "llama3.2"
)
```

This adapter supports text, streaming, tools, and the media protocols when the underlying endpoint supports them.

## Capability Guide

Text and streaming are the safest cross-provider assumptions. Tool calling requires `AIToolCallingModel`. Media APIs require `AIImageModel`, `AITranscriptionModel`, `AISpeechModel`, or `AIVideoModel`.

When a provider cannot support a call, SwiftyAI throws instead of silently pretending the feature exists.
