# Telemetry

SwiftyAI telemetry is explicit. The SDK gives you metadata, latency helpers, usage fields, and collector protocols; your app decides where the data goes.

## Record A Text Call

```swift
struct ConsoleTelemetryCollector: TelemetryCollector {
    func record(_ telemetry: AICallTelemetry) async {
        print(telemetry.metadata.operation)
        print(telemetry.latency.totalLatency ?? 0)
        print(telemetry.usage?.totalTokens ?? 0)
    }
}

let collector = ConsoleTelemetryCollector()
let recorder = startAICallTelemetry(
    operation: "generate.summary",
    provider: "openai",
    model: "gpt-4o-mini",
    name: "ticket-summary",
    attributes: ["screen": "support"]
)

do {
    let response = try await generateText(
        model: model,
        prompt: "Summarize this ticket."
    )

    await collector.record(
        finishAICallTelemetry(recorder, response: response)
    )
} catch {
    await collector.record(
        failAICallTelemetry(recorder, error: error)
    )
    throw error
}
```

`AICallTelemetry` includes metadata, latency, token usage, finish reason, and an optional error message.

## First Token Latency

For streams, record the first chunk separately.

```swift
var recorder = startAICallTelemetry(
    operation: "stream.chat",
    provider: "openai",
    model: "gpt-4o-mini"
)

var sawFirstToken = false
var lastUsage: TokenUsage?
var finishReason: String?

for try await chunk in streamText(model: model, prompt: "Stream a reply.") {
    if !sawFirstToken, !chunk.text.isEmpty {
        recorder = recordFirstToken(recorder)
        sawFirstToken = true
    }

    lastUsage = chunk.usage ?? lastUsage
    finishReason = chunk.finishReason ?? finishReason
}

let telemetry = finishAICallTelemetry(
    recorder,
    usage: lastUsage,
    model: "gpt-4o-mini",
    finishReason: finishReason
)
```

## Tool Telemetry

Tool loops can emit tool-level events through `ToolExecutionOptions`.

```swift
let result = try await generateWithTools(
    model: model,
    prompt: "Look up the order status.",
    tools: [lookupOrderTool],
    toolOptions: ToolExecutionOptions(
        onTelemetry: { event in
            print(event)
        }
    )
)
```

Use this for audit trails, debugging, and production dashboards that need to distinguish model time from tool time.
