# Tools

Tools let the model request your Swift functions during a generation loop.

## What it does

A tool has a name, description, input schema, and execution closure. The model decides when to call it, and SwiftyAI feeds the result back into the loop.

## Why it matters

Tools let models interact with live application capabilities such as search, calendars, databases, payment checks, and internal APIs.

## Before you start

1. Give each tool a clear name.

2. Describe exactly when the model should use it.

3. Validate tool inputs before touching external systems.

## Example

```swift
import Swifty_AI

let weatherTool = AITool(
    name: "get_weather",
    description: "Get the current weather for a city.",
    parameters: [
        "type": "object",
        "properties": [
            "city": ["type": "string"]
        ],
        "required": ["city"]
    ]
) { arguments in
    "Sunny and 24C"
}

let result = try await generateWithTools(
    model: model,
    prompt: "What should I wear in Bengaluru today?",
    tools: [weatherTool]
)

print(result.text)
```

## API notes

Prefer typed tools for app code and dynamic tools for MCP, plugin, or runtime discovered capabilities.
