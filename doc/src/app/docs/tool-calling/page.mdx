# Tool Calling

Tool calling runs a model, executes requested tools, and continues until the loop finishes.

## What it does

The SDK supports multi step loops, max step limits, custom stop conditions, approvals, interception, parallel calls, and tool error handling.

## Why it matters

Real agents need more than one model response. They need to inspect state, call functions, evaluate results, and produce a final answer.

## Before you start

1. Create tools with clear schemas.

2. Set `maxSteps` to prevent unbounded loops.

3. Use approvals for actions that mutate data or cost money.

## Steps

<Step title="Define tools">
Create tools for the actions the model may request.
</Step>

<Step title="Run the loop">
Call `generateWithTools` for a final response or a streaming tool API for progress.
</Step>

<Step title="Control execution">
Use stop conditions, interception, approval, and telemetry for safety.
</Step>

## Example

```swift
import Swifty_AI

let result = try await generateWithTools(
    model: model,
    prompt: "Find the user profile and summarize open tasks.",
    tools: [profileLookupTool, taskSearchTool],
    options: GenerationOptions(maxTokens: 800),
    maxSteps: 4
)

print(result.text)
```

## API notes

Emit user visible progress through [agent UI stream](/docs/agent-ui-stream). Record execution details through [telemetry](/docs/telemetry).
