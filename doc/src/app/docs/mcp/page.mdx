# MCP

MCP support lets SwiftyAI connect to Model Context Protocol servers through a transport abstraction.

## What it does

`MCPClient` initializes a protocol session, lists tools, calls tools, and adapts discovered MCP tools into executable SwiftyAI tools.

## Why it matters

MCP gives agents access to external capabilities without hardcoding every tool into your app. SwiftyAI keeps the core client transport agnostic.

## Before you start

1. Provide an `MCPTransport`.

2. Call `initialize` before tool operations.

3. Adapt tools only after discovery succeeds.

## Steps

<Step title="Create a transport">
Implement JSON data I/O for your server, process, or test mock.
</Step>

<Step title="Initialize the client">
Call `initialize` and let the client send `notifications/initialized`.
</Step>

<Step title="Use discovered tools">
Call `listTools`, adapt them to `AITool`, then pass them into [tool calling](/docs/tool-calling).
</Step>

## Example

```swift
import Foundation
import Swifty_AI

let client = MCPClient(transport: transport)
try await client.initialize()

let tools = try await client.listTools()
let sdkTools = tools.map { $0.asAITool(client: client) }

let result = try await generateWithTools(
    model: model,
    prompt: "Use available tools to inspect the project.",
    tools: sdkTools
)

print(result.text)
```

## API notes

The SDK ships client primitives, not a concrete network or stdio transport in this change.
