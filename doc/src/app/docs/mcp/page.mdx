# MCP

SwiftyAI includes a lightweight Model Context Protocol client. It handles JSON-RPC request shapes, initialization, tool listing, and tool calls. You provide the transport.

## Client Flow

```swift
import SwiftyAI

let client = MCPClient(transport: transport)

let server = try await client.initialize()
print(server.serverInfo.name)

let tools = try await client.listTools()
print(tools.map(\.name))

let result = try await client.callTool(
    name: "search_docs",
    arguments: [
        "query": .string("SwiftyAI generateText")
    ]
)
```

`initialize()` is cached. Calling it more than once returns the first successful result.

## Transport Boundary

The transport is intentionally small:

```swift
public protocol MCPTransport: Sendable {
    func send(_ data: Data, expectsResponse: Bool) async throws -> Data?
}
```

That keeps process management, stdio, HTTP, authentication, and sandboxing in your app. SwiftyAI only needs encoded request bytes and optional response bytes.

## Tool Data

MCP arguments use `MCPJSONValue` so values stay typed before encoding.

```swift
let result = try await client.callTool(
    name: "create_issue",
    arguments: [
        "title": .string("Docs typo"),
        "priority": .string("low"),
        "labels": .array([.string("docs"), .string("good first issue")])
    ]
)
```

The result contains MCP content blocks. Convert those blocks into the app representation you need before showing them in UI or sending them back to a model.

## Using MCP With Tool Loops

MCP tools and SwiftyAI `AITool` are separate types. A practical adapter usually lists MCP tools, builds matching `dynamicTool` values, and calls `client.callTool` from each tool executor.

```swift
let swiftyTool = dynamicTool(
    name: "search_docs",
    description: "Search project documentation.",
    inputSchema: .object(
        properties: [
            "query": .string(description: "Search query")
        ]
    )
) { arguments in
    let query = arguments["query"] as? String ?? ""
    let result = try await client.callTool(
        name: "search_docs",
        arguments: ["query": .string(query)]
    )
    return String(describing: result.content)
}
```

Keep approvals around MCP-backed tools. External tools can read files, call services, or mutate state depending on the server.
