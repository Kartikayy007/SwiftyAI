# SwiftUI Hooks

SwiftUI hooks are SDK state APIs for building AI features in Swift apps without shipping prebuilt views.

## What it does

`AIChat` and `AICompletion` are observable, main actor state types with synchronous `send`, `stop`, and `reset` methods.

## Why it matters

SwiftUI apps need state, cancellation, loading flags, errors, and optimistic updates. The hooks provide that behavior while leaving visual design to your app.

## Before you start

1. Choose a streaming model for chat.

2. Choose a text model for completion.

3. Keep state objects owned by your view or view model.

## Steps

<Step title="Create state">
Initialize `AIChat` or `AICompletion` with a model or registry string.
</Step>

<Step title="Bind input">
Connect `input` or `prompt` to your own controls.
</Step>

<Step title="Send and stop">
Call `send` synchronously and `stop` when the user cancels.
</Step>

## Example

```swift
import SwiftUI
import Swifty_AI

@Observable
@MainActor
final class AssistantState {
    let chat = AIChat(
        model: OpenAICompatibleProvider(
            baseURL: "https://api.openai.com/v1",
            apiKey: ProcessInfo.processInfo.environment["OPENAI_API_KEY"]!,
            model: "gpt-4o-mini"
        ),
        systemPrompt: "Be concise."
    )
}
```

## API notes

These are state APIs only. Use your own SwiftUI views and design system.
